# WanderLust - Travel Listing Web App

WanderLust is a full-stack travel listing platform inspired by Airbnb.  
Users can explore listings, create accounts, add new places, upload images, and manage travel stays.

## Features
- User Authentication & Authorization
- Add/Edit/Delete Listings
- Image Upload with Cloudinary
- Reviews & Ratings
- Responsive UI
- MVC Architecture
- MongoDB Database

## Tech Stack
- Node.js
- Express.js
- MongoDB
- EJS
- Bootstrap
- Passport.js
- Cloudinary
